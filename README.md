# Somnium — Сны и Рассудок

Мод для **Fabric (Minecraft 1.20.1, Java 17)**. Каждый сон в кровати переносит игрока в одно
из **9 кошмарных измерений** с собственной механикой и выходом. Бессонница разрушает рассудок,
а при низком рассудке кошмары **прорываются в реальный мир**.

## Сборка

Нужен **JDK 17 или новее** (Gradle ставить не нужно — есть wrapper).

```bash
gradlew.bat build      # Windows
./gradlew build        # Linux / macOS
```

Готовый мод: `build/libs/somnium-0.3.0.jar`. Для игры: Fabric Loader ≥ 0.14.21 и Fabric API
0.92.2+1.20.1. Других зависимостей нет.

JDK берётся из `JAVA_HOME`. Если нужен другой JDK, пропиши путь в своём
`%USERPROFILE%\.gradle\gradle.properties` (`org.gradle.java.home=...`), а не в файлах проекта.

## Цикл сна

1. Игрок ложится в кровать → 3 секунды затемнения → провал в сон.
2. Снимок яви (инвентарь, здоровье, голод, опыт, эффекты, точка у кровати) сохраняется
   **в NBT игрока**. В сон игрок уходит "чистым": пустой инвентарь, полное здоровье.
   С собой уходят только предметы с тегом `somnium:dream_carry` (Колокол Пробуждения,
   Меч Сноведений).
3. В кровати остаётся **спящее тело** со скином игрока; кровать занята и защищена от разрушения.
4. Название и цель сна — в чате, сверху — полоса оставшегося времени.
5. Во сне нельзя ломать блоки и разводить огонь (кроме творческого режима). Первые 12 секунд
   кошмары не атакуют.
6. Пробуждение возвращает игрока к кровати и полностью восстанавливает снимок. Если все
   (с учётом `playersSleepingPercentage`) спали — ночь пропускается.

Если игрок вышел с сервера посреди сна или сервер упал, при следующем входе он
просыпается в своей кровати со всеми вещами.

| Как проснуться | Исход | Рассудок |
|---|---|---|
| Выполнить цель сна | `SURVIVED_OBJECTIVE` | **+35** и 1-2 Эссенции Кошмара |
| Дожить до конца таймера | `SURVIVED_TIMEOUT` | +15 |
| Колокол Пробуждения, звон колокола у кровати, `/somnium wake` | `WOKE_EARLY` | +5 |
| Умереть во сне (смерть отменяется) | `DIED_IN_DREAM` | **−10** |
| Выход с сервера / перезапуск | `INTERRUPTED` | 0, бессонница не сбрасывается |

## Девять снов

| Сон | Время | Выход | Механика |
|---|---|---|---|
| **Тонущий город** | 5:00 | Колокол на вершине собора | Руины за крепостной стеной, вода поднимается; вне собора глубина тянет на дно. В соборе — лестница и пузырьковая колонна |
| **Лес теней** | 6:00 | 5 секунд в свете Дерева-Маяка | Тьма, ведьмины огни ведут к дереву. Шёпот звучит строго за спиной — обернёшься, и перед тобой встанет тень |
| **Пустошь зеркал** | 5:30 | 3 касания зеркала | Зеркало ускользает в новые места, Двойник (со скином игрока) идёт по следу и ускоряется |
| **Шахта-лабиринт** | 5:00 | Дверь в дальней ячейке | Лабиринт 20×20, Компас Выхода. Стены за спиной обрушаются и зарастают |
| **Кровавый пир** | 4:30 | Выпить Кубок Тоста | 5 блюд: свежие съесть, порченые сжечь Зажигалкой судей. Мясной Голем дремлет у стола и просыпается охранять кубки |
| **Пустота с глазами** | 4:00 | Дверь пробуждения **или** 5 "перехваченных взглядов" | Наблюдатели подкрадываются, когда на них не смотрят; взгляд в глаза 3 секунды сжигает Наблюдателя |
| **Сон-в-сне** | 7:30 | Уснуть в кровати внутри сна | Копия мира вокруг кровати без признаков сна. Через 20 секунд — ночь, гроза и надписи-обманки, зовущие к краю. Только при рассудке ≤ 20 |
| **Подъезд** | 3:00 | Люк в потолке последнего этажа | Марши строятся вверх, рушатся за спиной, осыпаются впереди и "заживают"; гнилые ступени ломаются |
| **Зеркальная комната** | 3:00 | Ниша света после победы | Отражение 20 секунд зеркалит движения за стеклом, потом нападает. Только при рассудке ≤ 50 |

Следующий сон выбирается случайно с учётом веса и рассудка, два последних сна не повторяются.

## Рассудок

- Шкала 0–100, хранится в NBT игрока. После 1 игрового дня без сна падает: 0.15/с → 0.35/с
  (1–3 дня) → 0.6/с. Во сне и в творческом режиме не падает.
- **Ловец Снов** в инвентаре замедляет падение вдвое. **Осколок Ясности** — +20 (перезарядка 60 с).
- Прорыв кошмаров (не во сне, не в творческом, не на мирной сложности, максимум 4 моба на игрока):

| Рассудок | Эффект |
|---|---|
| ≤ 50 | Редкие "эхо"-монстры ночью |
| ≤ 25 | Монстры последнего сна и днём |
| ≤ 10 | **Разрыв**: 2–4 монстра рядом, среди них Сталкер ("плачущий ангел") |

## Предметы

| Предмет | Назначение | Получение |
|---|---|---|
| Эссенция Кошмара | Ресурс | Дроп кошмаров; награда за выполненную цель сна |
| Осколок Ясности | ПКМ: +20 рассудка | 4 эссенции |
| Ловец Снов | Падение рассудка ×0.5 | 2 эссенции + осколок + 2 нити + палка |
| Колокол Пробуждения | ПКМ во сне — проснуться | 3 эссенции + золотой слиток → 2 шт. |
| Руда / слиток / блок сноведений | Портал в мир снов | Руда генерируется как медь |
| Меч Сноведений | Во снах даёт Силу II | 2 слитка + палка |

**Мир снов за порталом**: рамка 4×5 из блоков сноведений (как портал в ад), поджечь зажигалкой,
постоять в плёнке 4 секунды. Это постоянное измерение для прогулок — без правил снов.
Обратный портал возвращает туда, откуда вошёл (в т.ч. в Незер).

## Команды (уровень прав 2)

- `/somnium dream <сон> [игроки]` (или `/testdream <сон>`) — сразу отправить в сон.
- `/somnium wake [игроки]` — разбудить.
- `/somnium sanity get|set|add ...` (или `/sanity ...`) — рассудок.
- `/somnium sessions` — активные сны.

## Мультиплеер

- Заснувший в течение 10 секунд после начала чужого сна (в том же измерении) присоединяется
  к нему: общая сцена, общий таймер, общая победа там, где цель общая (зеркала, взгляды, люк).
- Разные группы с одним и тем же сном не мешают друг другу: каждый сон строится в своём
  участке измерения (слоте). После сна участок в фоне очищается порциями, без лагов.
- Звон обычного колокола будит тех, чья кровать в радиусе 5 блоков.

## Датапаки

Сны описаны в `data/<namespace>/dream/*.json` и перезагружаются по `/reload`:

```json
{
  "name": "somnium.dream.drowning_city",
  "objective": "somnium.dream.drowning_city.objective",
  "dimension": "somnium:dream_drowning_city",
  "scenario": "somnium:drowning_city",
  "monsters": ["somnium:drowned_wretch", "somnium:phantom_eel"],
  "weight": 20,
  "max_sanity": 100,
  "duration_ticks": 6000
}
```

`scenario` — один из встроенных Java-сценариев (`drowning_city`, `shadow_forest`, `mirror_wastes`,
`collapsing_mine`, `crimson_feast`, `void_of_eyes`, `dream_within_dream`, `stairwell`, `mirror_room`).
Предметы, которые уходят в сон, задаёт тег `data/somnium/tags/items/dream_carry.json`.

## Структура кода

- `dream/DreamManager` — засыпание, вход, тик, пробуждение, восстановление после обрыва.
- `dream/DreamSession` — один экземпляр сна (участники, слот, сущности сна).
- `dream/DreamSnapshot` — снимок яви и его NBT.
- `dream/DreamSlots` — слоты измерений и фоновая очистка.
- `dream/scenario/*` — по классу на сон; состояние сна — поля сценария.
- `dream/DreamRegistry` — загрузка снов из датапака.
- `sanity/*`, `event/BleedThroughManager` — рассудок и прорыв.
- `player/SomniumPlayerState` — данные мода в NBT игрока.
- `portal/DreamPortalManager`, `dream/DreamPortalHelper` — портал и мир снов.
- `event/SomniumEvents` — все подписки на события; `command/SomniumCommands` — команды.
- `client/*` — HUD, рендеры (спящее тело и отражения рисуются скином игрока).
